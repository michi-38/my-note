# 企画骨子：③別れ・復縁系「振った側・連絡を絶った側の心理」

作成日: 2026-08-28
参照元: `note事業部/1_リサーチ担当/男性心理女性心理系・別れ復縁系_深掘りリサーチ.md`（③別れ・復縁系「まだ埋まっていない切り口」）

---

## 想定読者と悩み

**想定読者**：別れた相手、または音信不通にしてきた相手について、「なぜ何も言わずに離れていったのか」がわからないまま宙ぶらりんな気持ちでいる女性。

**悩みの言葉（リサーチより）**
- 「音信不通 復縁 諦めるべきか」
- 「半年以上音信不通で復縁した人はいますか」
- 「音信不通になってしまった人と復縁できた方っていますか」
- 「別れた後の元彼の本音」「元彼 未練」

リサーチで確認した通り、「冷却期間の過ごし方」「連絡再開のタイミング」といった**方法論の記事はすでに多い**。読者がまだ出会えていないのは、「相手の中で実際に何が起きていたのか」という**心理の中身そのもの**。この記事は方法論ではなく、心理の解説に絞る。

---

## 章立て（見出し構成）

事業部ルールに従い、見出しでは結論を先出しせず、章内に小見出しは作らない。各章1本の流れで書く。

| 章 | 核心・結論（1行） | 使う具体例・比喩（1行） |
|---|---|---|
| 第1章（無料） | 黙って去っていく人の中でも、実は何も感じていないわけではない、という入り口を示す | 相談の中でよく聞く「急に連絡が来なくなった」というケースの情景を描写する |
| 第2章（無料） | 相談を受けてきた中で見えてきた「よくあるパターン」の存在をほのめかす（結論は明かさない） | 具体的な相談エピソードを1つ、名前を伏せて紹介する |
| ── 有料部分の境界線 ── | | |
| 第3章（有料） | 連絡を絶つという行動の裏にある心理パターンを、相談実績から見えてきた範囲でいくつか言語化する | パターンごとに、実際にあった相談の言い回しを短く添える |
| 第4章（有料） | 時間が経つにつれて、その心理がどう変化していくか | 「最初は◯◯だったのが、時間が経つと◯◯に変わっていく」という時系列の具体例 |
| 第5章（有料） | 待っている読者が、この時期にできること・気をつけたいこと（方法論に深入りしない） | 「健康診断のチェック項目に◯をつけるだけの感覚で」のような噛み砕いた比喩を使う |
| 第6章（有料・まとめ） | 読者への言葉で締める | ─ |

---

## 無料部分と有料部分の境界線

**第2章の終わりで区切る。**

- 無料部分（第1〜2章）：読者の状況への共感＋「実はよくあるパターンがある」という存在の提示まで
- 有料部分（第3〜6章）：心理パターンの中身そのもの＋時間経過による変化＋読者が今できること

ペイウォール直前のコピーは、承認済みの型を使う想定：

> 「ここからは◯つのテーマを深掘りして詳しく解説しています。あなたの気になるテーマから読んでみてください。」

第3章で扱う「心理パターン」の数（3つ〜4つ想定）を、そのまま「◯つのテーマ」に当てはめる形にする。

## 確認したいこと（本文に進む前に）

「振った側・連絡を絶った側の心理」というテーマは、みちさん自身が**振った側・音信不通にした側として体験したこと**なのか、それとも**40年近い相談経験の中で、そういう相手について語られるのを聞いてきた側の知見**なのか、どちらの立場で書くかによって一人称の語り口が変わります。
