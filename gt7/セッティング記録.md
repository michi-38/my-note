## メモ
- 操舵スピード補正：数字が小さいほどハンドルの切れが穏やか、大きいほど鋭い。良いと感じた範囲は -1〜2。最終的に0と-1で比べ、ベストタイムが出た-1に決定。
- お手本は「ライン・ハンドルを切り始める場所」の参考に。ギア・ブレーキ・アクセルはYouTuberを参考に。
- フルブレーキ時に左スティックを押してしまうクセあり → ブレーキ直前に親指の力を抜く。
- ゴースト追走は「タイミング」ではなく「場所」を真似する。
- スローイン・ファストアウト：ラインからはみ出すくらいなら、スピードを落としてライン通りに走る。ブレーキの目印を決めて守る。

### 最初のヘアピン後の「左→右→左」（トンネル手前）
- 3つ目の左：2つ目の右の出口は左側までふくらんでOK。その後、**車の頭を右（外側）に向けて右側へ移動してから**左に入る → ライン通りに走れた（YouTuber・お手本も同じ動き）。
- 2つ目の右：切り返しはスティックをゆっくり。間はR2を少し踏んで一定に。
- YouTuberは④（1つ目の左）〜⑤（2つ目の右）の間でブレーキを踏んでいない（ABSランプ点かず）。R2の加減だけで曲がる。
- ⑥（3つ目の左）の手前：YouTuberは3速に落とすときにABSとカウンターステアアシスト（タコメーター右）が両方点灯。強めのブレーキを残したまま曲がり始め、お尻を少し流して向きを変えている（最初のヘアピンと同じ走り方）。
- ⑥の本当の一番遅い速度：YouTuber 119km/h ／ 自分 109km/h（手前の最高速度 143 → 119 で-24、自分は 139 → 109 で-30。減速量が6km/h多い）
- ⑤出口135 → ⑥ブレーキ直前132（-3） → ⑥救急車横114（YouTuberは⑤141 → ⑥手前143 → ⑥120）。⑤〜⑥の間で加速できていないのが課題。
- ⑥：救急車より手前の目印で左に切り始め、出口が見えるまで左に倒したまま → ⑥ブレーキ直前137km/h、救急車横118km/h（YouTuber 143 / 120）。壁に当たらず曲がれた。

## 練習の進め方（本人の方針）
1. 区間1：YouTuberの走り方を真似して、区間タイムをYouTuber（30.069）に近づける
2. 区間1で30秒台が出たら、そのまま走り続けて区間2の練習に進む
3. 各区間は同じ手順：YouTuberの速度をコマ送りで測る → 自分の速度と比べる → 差が大きい場所から1か所ずつ直す

## 区間1の失敗パターン（9回中8回失敗したとき）
多い順：
1. ⑥：インに寄りすぎ → アウトにふくらんでコースアウト（切り始めが早い＝頂点が早い）
2. ⑤の出口：左（外側）にコースアウト（出口の速度が高すぎる・R2が早い）
3. 最初のヘアピン：オーバースピードでコースアウト（ブレーキが遅い）
- 対策：各所に「目印」を決めて毎回同じ場所で操作する。区間1は9割で走り切る。
- 区間2：ライン表示（アシストライン）の上を走ると、イン側に寄れてYouTuberのラインに近くなる。ラインは表示に従い、ブレーキの位置はYouTuberを優先する。
- ⑪で外へ流れる（ランプは何も点かない）→ 前のタイヤが曲がり切れていない（アンダーステア）。入る速度・ブレーキを離すタイミング・頂点の位置を見直す。
- ⑥（救急車）：速度を少し落とすと、出口でイン側に残れた → 区間1が31.177（最近で一番良い）。
- ⑫：最低75km/h → 出口90km/h（少しスピン）／最低64km/h → 出口89km/h（スピンなし）。次は最低70km/h前後でスピンせず出口90km/h以上を狙う。
