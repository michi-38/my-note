# はじめに：なぜ「男の本気度」は言葉ではなく行動でしか分からないのか

はじめまして。このnoteを開いてくださって、ありがとうございます。

### 10代の頃から、なぜか恋愛相談をされるのが好きだった私

大阪出身の57歳、男です。恋愛の専門家でも、プロでもありません。ただ、10代の頃から、なぜか周りの人に恋愛相談をされることが多い人生を送ってきました。

自分から聞き役を買って出ていたわけではありません。ただ、相談してくれた人の話を聞いていると、その相手（第三者）が今どんな気持ちでいるのか、なんとなく見えてくることが多かったんです。不思議と、その感覚だけはずっと変わらず、気づけばこの歳になっていました。

面白いことに、これだけ他人の恋愛はわかるのに、自分自身の恋愛となると話は別です。人の気持ちはなんとなくわかっても、自分のこととなると急にわからなくなる。今でもそうで、正直なところ、あまり自慢できる話ではありません。だからこそ、このnoteでお伝えすることは、難しい理論や資格に基づいたものではなく、あくまでなぜか人に相談されてきた中で見えてきた、一つの視点だと思って読んでいただけたらうれしいです。

### 「好き」とはっきり言わない男性心理

相談を受けていて感じるのは、「好きです」とはっきり言葉にできる男性は、実はそれほど多くないということです。

振られるのが怖い、今の関係が壊れるのが怖い、自分に自信が持てない。理由は人それぞれですが、共通しているのは、**気持ちを言葉にすることと、気持ちを持っていることは、別の話だ**という点です。言葉にしないからといって、気持ちがないとは限りません。

だからこそ、「言ってくれないから、脈なしなんだ」と結論づけてしまうのは、少しもったいないことでもあります。

### 言葉より行動を見るべき理由

では、言葉に頼れないなら、何を見ればいいのでしょうか。答えは、**行動**です。

言葉は、その場でいくらでも選んで話せます。でも、無意識にやってしまう行動までは、なかなかコントロールしきれません。だからこそ、言葉よりも行動、その中でも特に**無意識に出てしまう部分**にこそ、その人の本当の気持ちが表れます。このnoteでこれから紹介していくサインは、すべて「相手が意図的に見せているもの」ではなく、「相手が気づかないうちに出てしまっているもの」を中心に選んでいます。この考え方の詳しい中身は、第1章で改めてお伝えします。
