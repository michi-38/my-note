# 『脈ありサインの見抜き方｜男性の本気度を行動から判断する方法』目次

読者：恋愛に悩んでいる女性。リサーチ（動画タイトル傾向・記事の内容傾向）で繰り返し出てきた要素を統合し、重複が起きないよう5章構成にしている。

**はじめに：なぜ「男の本気度」は言葉ではなく行動でしか分からないのか**
- 10代の頃から、なぜか恋愛相談をされるのが好きだった私
- 「好き」とはっきり言わない男性心理
- 言葉より行動を見るべき理由
- この本を読むとわかるようになること

**第1章：脈ありサインその前に、思い込みを外して"見る目"を作る**
- 「優しい」は全員に対してかもしれない、という視点
- 既読・いいねの数だけでは判断できない理由
- 無意識の行動には本音が出る、という前提
- 比較の視点の作り方（誰と比べるか、いつと比べるか）

*→ 本の中で唯一「思い込み・比較の考え方」を教える場所。以降の章はここで教えた視点を使うだけで、説明を繰り返さない。*

**第2章：会話でわかる本気度**
- 話題の選び方
- 質問の深さ
- 将来の話が出るか
- 沈黙の心地よさ

*→ 対面での「会話」だけを扱う。LINE・行動には触れない。*

**第3章：LINE・SNSでわかる本気度**
- 既読の速さより、内容の濃さを見る
- 自分から連絡してくる頻度
- スタンプ・言葉づかいの崩し方
- ストーリー・いいねの本当の意味

*→ 第1章の「既読・いいねは証拠にならない」を受けて、「では何を見るか」だけをここで答える。理由の説明は繰り返さない。*

**第4章：態度・行動でわかる本気度**
- 二人になろうとする誘い方
- 変化に気づいてくれるか
- 特別扱い・頼られたい行動
- 人前と二人の時の態度の差
- 冗談やいじりに隠れた好意

*→ デート・職場・友人関係すべての「対面の振る舞い」をここに集約。「人前と二人の態度の差」は第1章の比較の視点をそのまま適用するだけで、視点自体の説明はしない。*

**第5章：サインを見つけたら、次にどうする**
- 確信する前に確認すべきこと
- 動くべきタイミングの見極め方
- 距離を縮める3つのステップ
- 勘違いだったときの切り替え方

**おわりに：昔から恋愛相談をされてきて、伝えたいこと**
- なぜか人から恋愛相談をされる人生だった
- 完璧な診断はない、それでも行動は嘘をつかない
- あなたの恋を応援したい理由
