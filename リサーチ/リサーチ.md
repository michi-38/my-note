そのため、本来のご依頼内容（①直近半年以内 ②登録者数が少ないのに再生数が伸びている ③その基準で10本選定 ④文字起こしから伸びている理由を抽出）は、**この環境単体では実行不可能**でした。

## 2. タイトル・訴求文言から読み取れる傾向（仮説）

文字起こしが取得できないため、**唯一検証可能なデータであるタイトル・キャッチコピーの言葉選び**を分析しました。伸びている証拠にはなりませんが、「クリックされやすい／検索に強い切り口」の傾向として参考になります。

### 見出しに共通する要素の抽象化

1. **数字で具体性を出す**：「25選」「20個」「6選」「100選」「3カ所」など、曖昧な"サイン"を数値化して"網羅感"と"チェックリスト感"を演出している。
2. **対象を性別・属性でピンポイントに絞る**：「女子の」「男子の」「アラサー恋愛」のように、読者が「自分ごと」と即座に判断できる主語設定になっている。
3. **煽り・呼びかけ口調で当事者意識を刺激する**：「気づいて？」「見逃さないでね」「今すぐチェックして」「逃すんじゃねえぞ」など、命令形・語りかけ形で"自分が見落としているかもしれない"という焦りを喚起している。
4. **権威付け・エビデンスを添える**：「インスタ3000人調査」「99%が勘違いしてる」「恋愛科学」など、根拠らしきものを添えて信頼性を補強している。
5. **意外性・逆説を打ち出す**：「多くの男性が気づけない」「隠れた」「意外すぎる」など、"知っているようで知らない"というギャップを提示している。
6. **即効性・時短を訴求する**：「30秒でわかる」のように視聴コストの低さを明示し、ショート動画的な離脱防止をしている。
7. **診断×エンタメのハイブリッド企画**：「恋愛大好き女2人が判定したら辛口すぎWWW」のように、単なる解説ではなく"リアクション性・ドラマ性"を持たせて視聴継続を狙っている。
8. **シリーズの総集編化**：「総集編」「一気見用」のように、既存の人気コンテンツを再編集し、検索流入・アルゴリズム露出を両取りする構成も見られる。

## 3. 共通点まとめ表（タイトルベースの仮説）

| 要素 | 内容 | 具体例（タイトルより） |
|---|---|---|
| 具体性の数値化 | サインの個数を明示し「チェックリスト」感を出す | 「25個」「20個」「6選」「100選」 |
| 対象の限定 | 性別・年代・恋愛ステータスで主語を絞る | 「女子の」「男子の」「アラサー恋愛」 |
| 呼びかけ・命令形 | 視聴者に直接語りかけ、当事者意識を持たせる | 「気づいて？」「今すぐチェックして」「逃すんじゃねえぞ」 |
| 根拠・権威付け | 調査データや"科学"を根拠として添える | 「インスタ3000人調査」「恋愛科学」「99%が勘違い」 |
| 意外性・逆説 | 「知らなかった」を強調しギャップで惹きつける | 「多くの男性が気づけない」「意外すぎる」 |
| 即効性 | 視聴のハードルの低さを明示する | 「30秒でわかる」 |
| エンタメ性 | 診断＋リアクション・企画性で飽きさせない | 「辛口すぎWWW」「2人が判定」 |
| 再編集・総集編化 | 過去コンテンツをまとめ直して検索流入を狙う | 「総集編」「一気見用」 |

## 4. あなたのnote企画への示唆

- タイトル・見出しの型は、noteの**タイトル付け**や**見出し構成**にそのまま転用できます（例：「40年の相談経験でわかった、脈ありサイン20選」「9割の人が見逃してる"別れ話"の本音」など）。
- ただし「本当に伸びている動画かどうか」は未検証のため、**このタイトル傾向を鵜呑みにしてnoteの構成を決め切るのはリスクがあります**。可能であれば次の「次のアクション」で精度を上げることをおすすめします。

## 5. 次のアクション（精度を上げたい場合）

1. **動画URLを直接共有してもらう**：手元でYouTube検索し、条件に合いそうな動画のURL/IDを教えてもらえれば、そのページ単位でアクセス可否を再確認します（同じドメインブロックで失敗する可能性はありますが、部分的に取得できるページがあれば深掘りします）。
2. **登録者数・再生数・字幕テキストを手動で共有してもらう**：スクリーンショットやコピペで構いません。それをもとに「なぜ伸びているか」の抽象化と共通点の表を、確度の高い形で作り直します。
3. **環境管理者にYouTubeドメインの許可を依頼する**：許可されれば、`yt-dlp`で検索・メタデータ取得・自動字幕取得までこちらで実行できます。
